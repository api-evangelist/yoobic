# YOOBIC

> YOOBIC is a frontline employee experience platform for retail and distributed
> workforces, unifying task management, communications, and microlearning. The
> YOOBIC Public API is a RESTful JSON API for managing users, stores, missions
> (tasks), campaigns, learning, communities, and webhooks programmatically.

Generated by the API Evangelist enrichment pipeline from the YOOBIC Public API
documentation and OpenAPI. Base URL: https://api.yoobic.com/public/api
(sandbox: https://api-sandbox.yoobic.com/public/api). Auth: JWT bearer token
via POST /public/api/auth/login. HTTPS only, TLS 1.2+.

## API

- [OpenAPI 3.0 specification](https://docs.yoobic.com/openapi.json): 230 paths, 265 operations, 41 resource groups.
- [API documentation](https://docs.yoobic.com/api.html): Public API reference, access, requests/responses, async jobs.
- [Postman collection](https://assets.yoobic.com/raw/upload/v1767016464/3c85c240-dd03-4981-9814-bc6e5e861fa0.zip): all endpoints with sandbox/prod environments.

## Conventions

- Auth: `Authorization: Bearer <jwt>`; obtain via POST /auth/login, revoke via POST /auth/invalidate_token.
- Pagination: URL-encoded JSON `filter` with `limit` (max 1000) and `skip`; response `paging{skip,limit,total}`.
- Filtering: `order`, `where`, `fields` (sparse fieldsets) inside the `filter` parameter; `/{resource}/count` for totals.
- Bulk/async: `GET /{resource}/export?type=csv|excel` and `POST /{resource}/import` return a job id; poll `/jobs`.
- Errors: JSON `{data, error}` envelope; statuses 400/401/403/404/405/429/501. Not RFC 9457.
- Rate limits (per organization): 10 req/s overall, 120 DELETE/min, 180 users-write/min, 100,000/day; headers ratelimit-limit/remaining/reset; 429 on breach.
